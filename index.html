About This Project

This project demonstrates how developers use Git and GitHub in real-world software development. It covers version control, commits, branches, pull requests, code reviews, and merge conflict resolution.

View GitHub Repository

Project Workflow

  1. Create a local Git repository.
  2. Create and update project files.
  3. Stage changes using git add.
  4. Save changes using git commit.
  5. Push code to GitHub.
  6. Create feature branches for new tasks.
  7. Submit Pull Requests for code review.
  8. Merge approved changes into the main branch.
  9. Resolve merge conflicts when they occur.

Essential Git Commands

  • git init — Initialize a repository.
  • git status — Check file changes.
  • git add . — Stage changes.
  • git commit -m "message" — Save a commit.
  • git branch — List branches.
  • git switch -c feature/update-page — Create a feature branch.
  • git push -u origin main — Push the main branch.
  • git log --oneline — View commit history.
