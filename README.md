# My First Git and GitHub Project

## About This Project
This is my first hands-on project to practice Git and GitHub.

## Project Objectives
- Learn Git basics.
- Create and manage a GitHub repository.
- Track code changes using Git.
- Practice commits and push changes to GitHub.

## Technologies Used
- Git
- GitHub
- HTML

## Project Files
- `README.md` — Project documentation.
- `index.html` — Simple HTML webpage.

## What I Learned
- `git init` — Initialize a Git repository.
- `git add` — Stage file changes.
- `git commit` — Save changes in Git history.
- `git push` — Upload commits to GitHub.
- `git status` — Check the working tree status.
- `git log` — View commit history.
